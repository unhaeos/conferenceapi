# 📢 ConferenceAPI

A lightweight RESTful API for retrieving academic conference data including papers, authors, topics, and affiliations.

📄 **Postman Docs**: [View Full API Documentation](https://documenter.getpostman.com/view/41779560/2sAYkErzt7)

---

## 🚀 Features

- View papers, authors, topics, and affiliations
- Filter papers by topic, affiliation, or author
- Simple, unauthenticated GET-only API
- Perfect for demos or educational purposes

---

## 📦 Tech Stack

- PHP (REST API)
- SQLite (Lightweight database)
- Apache (Web server)
